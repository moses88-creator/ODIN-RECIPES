# Odin Recipes 

A digital cookbook website built from scratch as part of **The Odin Project: Foundations** curriculum. This project demonstrates foundational frontend skills, structural layout principles, and version control workflows.


You can view the live project running on the web here:
(https://moses88-creator.github.io/ODIN-RECIPES/)

##  What I Learned
Through building this project, I mastered several core development pillars:
* **Structural HTML:** Organizing content using semantic typography tags (`<h1>`, `<h2>`), paragraphs, and breaks.
* **Relative Path Navigation:** Nesting directory files (`recipes/`) and linking them seamlessly back to a root homepage using relative file pathways (`../index.html`).
* **Media Embedding:** Embedding hosted visual content via image components (`<img>`) and configuring accessibility alt-text descriptions.
* **Lists Architecture:** Organizing text sequences utilizing both unordered bullet styles (`<ul>`) and ordered progression numbering (`<ol>`).
* **Version Control Workflow:** Tracking project increments locally using **Git** (`add`, `commit`) and deploying pipelines remotely via **GitHub** and **GitHub Pages**.

## Built With
* Pure HTML5
* Git & GitHub (SSH Authentication)
* Ubuntu Linux via WSL2
